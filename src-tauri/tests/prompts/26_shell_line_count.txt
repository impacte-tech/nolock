Create a shell script at count.sh that counts the number of lines in a file and prints the count. First create data.txt with 5 lines, then run `bash count.sh data.txt` and report the printed output.

This is a mechanical shell-script task. If a dedicated micro-agent for running shell scripts is available (e.g. shell-runner), delegate the write-and-run work to it via spawn_micro_agent and report the output it returns. Otherwise, do it yourself with write_file and bash_sandbox.
